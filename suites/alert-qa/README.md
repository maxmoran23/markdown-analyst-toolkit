# Alert Adjudication Quality Review

Reperform case reasoning, distinguish demonstrated defects from missing reviewability, calibrate independent judgments and define evidence-based remediation closure.

**Decision:** Which supplied adjudications meet the applicable quality rubric, which need substantive repair, and which cannot yet be assessed?

Use this suite for alert quality reviewers, investigation leads and calibration facilitators. It contains exactly twelve Markdown files. Attach 01 through 10 for the working session; README and 11 are navigation and build evidence. All required methods, schemas, complete fictional inputs, populated outputs, controlled counterexamples and executable fixture arithmetic live inside these attachments. End users need no repository, terminal, connector or automation.

Start with 01, establish actual scope and supplied policy, then follow 02–05. Files 06–08 contain fixed report, workbook and offline dashboard templates. File 09 supplies acceptance tests. File 10 contains the complete worked case and an optional standalone Python arithmetic check that can run inside an already available approved chat capability. If that capability is unavailable, the printed raw records and expected calculations remain complete.

The specimen is fictional and the criteria are explicitly illustrative. Replace every example source, amount, finding and conclusion when adapting. Public authorities provide methodological context; they are not evidence about the fictional subjects. Actual human decisions, external communications and operational actions remain separate from this review package.

## Included domain registers

| register | grain | fixture_rows |

| QualityCriteria | One supplied illustrative quality criterion; no implied universal legal mandate. | 8 |
| DefectRegister | One defect-condition per case/criterion; multiple defects could affect one case. | 7 |
| Calibration | One paired case assessment; preserve original votes and later consensus. | 12 |

| ProcessQA | One reperformable quality metric or authorization check. | 10 |

An illustrative reproduction budget is **373,900–934,750 tokens** (4–10× content; heuristic, not observed usage). Actual generation tokens and monetary cost were not captured per suite.
