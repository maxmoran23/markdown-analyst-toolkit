# Digital Asset Review

Turn supplied public-ledger records into a reproducible event summary while keeping transfers, execution status, token units, and third-party identity labels separate. The pack emphasizes evidence quality and explanatory limits.

## In plain English

- You bring a specific question and public information you are allowed to use.
- Attach the ten numbered files 01–10 to one AI chat and paste the launch prompt in 01.
- The chat organizes evidence, applies the method, shows gaps, and fills the fixed templates.
- You review the answer and make the decision. The chat does not act on it for you.

Start with the network, subject address or synthetic ID, asset contract, block/time window, and source capture. Do not start from a screenshot total without the records and units that produced it.

## What you receive

An event reconciliation, counterparty table, source/attribution assessment, and a report explaining exactly what the supplied ledger records do and do not establish. The report explains the answer, the workbook keeps the supporting records, and the optional HTML dashboard makes the same records easier to review. If the chat cannot create downloadable files, it supplies a complete Markdown report and exact-column tables. You do not need a terminal, automation platform, repository connection, or special agent setup.

## How this was built

The build sequence is: define the decision → verify relevant public references → author the evidence and analytical rules → construct a fictional worked case → specify fixed report/workbook/dashboard contracts → check consistency and review limitations. See 11-build-record.md for recorded checks, actual build stages, and the content-size estimate. Build token consumption and cost are unknown without telemetry; a token estimate of the published text is a content-size estimate, not a bill or a measure of quality. No duration or independent review should be inferred from this description.

## Limits that matter

An address is not a person, a transaction is not necessarily a successful transfer, a token symbol is not asset identity, and exposure is not proof of intent. This pack does not connect a wallet, sign transactions, trace private data, or make a compliance disposition. Guidance was consulted during authoring on 2026-10-09 where explicitly recorded in 02. Refresh changing sources when using the pack. A completed template does not certify compliance or prove the absence of risk.
