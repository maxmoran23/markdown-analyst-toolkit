# Customer Risk Review

Review a customer profile with transparent factor weighting, evidence gaps, material exceptions, and human rating decisions.

The decision is: **What review priority and additional evidence are supported, and which rating decisions remain for an authorized human?** This suite supports a documented analytical draft for human review. It does not assign a live customer rating, approve a relationship, clear a payment, authenticate private records, or establish regulatory compliance. Its case examples are invented and its numeric conventions are teaching methods. A mathematically exact result can still rest on uncorroborated inputs.

## Manual attachment workflow

Open a new AI session and attach the files required by the stage table in 01-session-guide.md. The full workflow uses 01 through 10. A smaller Example check stage reproduces the fixture first; Analyze preserves a complete case checkpoint; Render uses that checkpoint with one chosen output template. README and 11-build-record.md are orientation material. No terminal, installation, repository connection, connector, scheduler, unattended agent, or integration is required for an end user.

Readability and artifact support must be checked in the actual session. If the session cannot create a requested file, require the complete report text or corresponding delimited tables and label the format unverified. Do not accept an empty download, a claim that a file was tested without inspection, or an asserted prior example pass without the preserved record. In-session tools can assist calculations when available; showing reproducible arithmetic remains mandatory.

## Start with a bounded question

State the decision, review cutoff, included population, unit of analysis, permitted sources, desired artifacts, and reviewer role. Identify whether the work is an exercise or a public-source research task. Attach the selected stage files and say: “Follow the stage contract in 01. Preserve uncertainty, reproduce the relevant example checks, and keep recommendations separate from human decisions.” Do not paste sensitive case records into an unapproved environment.

Every case must preserve its evidence register, assumptions, raw accepted rows, exclusions, calculations, conclusions, alternatives, proposed actions, and tests actually performed. A saved executive summary is insufficient to resume analysis or render defensible tables. Public source links are starting points; they are not an automatically refreshed legal inventory. The analyst must establish applicable jurisdiction and current authority for any real use.

## Build and attachment budget

The ten instructional files contain **17,766 words** and approximately **39,324 attachment tokens** (characters ÷ 4, rounded up; code included). This is content size, not build consumption. An illustrative reproduction budget is **157,296–393,240 tokens** (4–10× content; heuristic, not observed usage). Actual generation tokens and monetary cost were not captured per suite.
