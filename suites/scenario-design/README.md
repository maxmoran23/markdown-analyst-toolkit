# Transaction Monitoring Scenario Design

Translate a risk hypothesis into a fully specified, reproducible monitoring rule, with temporal semantics, evidence gates, suppression boundaries and populated acceptance tests.

**Decision supported:** Does the proposed rule implement its stated hypothesis without ambiguous fields, boundary behavior, exclusions or delivery decisions?

This is a complete manual analytical attachment suite. Attach files 01 through 10 in a permitted AI session, or use the explicit staged workflow in file 01 when the context is smaller. README and 11-build-record are browse-only; the complete suite contains twelve Markdown files. End users need no terminal, connector, repository checkout, installation, scheduler or agent builder.

The authored process fixes the source grains, input dictionary, ordered gates, exact formulas, temporal and currency semantics, missing-data branches, contextual review boundaries, output schemas and quality expectations. File 10 contains the entire fictional source and every populated intermediate register, plus independently reset alternate cases. Files 06–08 contain complete fixed renderers for reports, workbooks and an optional offline dashboard. A human retains consequential decisions.

Synthetic reproduction demonstrates the behavior of these cases only; it does not establish production detection accuracy, legal compliance, complete data coverage or platform support. Keep the source, raw result, contextual interpretation and human disposition separate.
