## Fictional question and frozen parameters

Every record, date, role, outcome, and draw below is fictional. SYN-001 denotes this complete example. The intended finite population is twelve approval opportunities during Sep 01–30, 2026. Each opportunity must have evidence of a reviewer distinct from its preparer before release. A clear same-role approval is FAIL; documented distinct roles before release is PASS; unavailable execution evidence is UNABLE TO CONCLUDE. Retention is not separately classified as an execution failure in this exercise.

The H stratum contains four elevated-complexity opportunities. The L stratum contains eight ordinary opportunities. Those labels are assigned before outcomes. Both strata are sampled without replacement using the stipulated probability mechanism below. H has n = 3 and L has n = 4. The requested inference is an upper bound on each stratum's fixed-period failure fraction when its selected outcomes are complete. The confidence level is 95%, one-sided, alpha = 0.05. The illustrative acceptance threshold for L is an upper bound no greater than 25.0%; it is an author-defined exercise condition, not a regulatory standard.

The complete fictional master schedule and frame agree on twelve IDs. There are no exclusions, duplicate rows, or omitted opportunities within the fixture. This stipulation is the frame evidence for the exercise only. A real review needs independent extraction and completeness evidence.

## Fully specified selection and replay

Sort H01–H04 and L01–L08 ascending. Enumerate increasing combinations within each stratum lexicographically, zero-based. A fictional independent uniform ticket draw selected rank 2 from H's four combinations and rank 49 from L's seventy combinations before outcomes were inspected. The ranks are supplied test inputs, not measured randomness generated by this document. Every combination has equal stipulated probability, giving each H unit inclusion probability 3/4 and each L unit 4/8. Verify that premise separately in any real use.

H combinations in rank order are (H01,H02,H03), (H01,H02,H04), (H01,H03,H04), and (H02,H03,H04). Thus rank 2 gives H01,H03,H04. L rank 49 gives L02,L04,L06,L08. The following optional in-session code independently enumerates the same finite lists. Manual enumeration is also valid; no end-user terminal is required.

```python
from itertools import combinations
from math import comb
h = ['H01', 'H02', 'H03', 'H04']
l = ['L01', 'L02', 'L03', 'L04', 'L05', 'L06', 'L07', 'L08']
h_selected = list(combinations(h, 3))[2]
l_selected = list(combinations(l, 4))[49]
assert h_selected == ('H01', 'H03', 'H04')
assert l_selected == ('L02', 'L04', 'L06', 'L08')
N, n, alpha = 8, 4, 0.05
zero_tails = {
    D: (comb(N-D, n) / comb(N, n) if N-D >= n else 0.0)
    for D in range(N+1)
}
U = max(D for D, tail in zero_tails.items() if tail > alpha)
assert U == 3
assert U/N == 0.375
binomial_upper = 1-alpha**(1/n)
print(h_selected, l_selected, zero_tails, U/N, binomial_upper)
```

No randomness is called in this replay code. It verifies the mapping from recorded draw to selected IDs and the conditional arithmetic. It does not prove a selector used uniform tickets or concealed outcomes. Preserve that limitation in the final conclusion.
