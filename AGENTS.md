# Maintainer instructions

This public reference library contains Markdown attachment suites for manual AI sessions.
End users need no shell, scheduler, repository integration, connectors, or agent builder.
Each suite contains exactly twelve Markdown files, including its README and build record.
All substantive runtime instructions must be inside the selected suite, with no required
cross-suite or external repository file. Links to public authorities support research;
links are not evidence that content was retrieved or reviewed.

Use only generic methods, public source references, and clearly fictional examples.
Never include employer names, internal policies, personal paths, account details,
credentials, real customer records, or real sanctions targets as example data.
Do not claim regulatory compliance, production validation, platform support, or model
reliability from synthetic checks. Platform capabilities are tested per session.

Keep evidence class, confidence, severity, recommendation, and human disposition distinct.
Never treat missing data as a pass or silently omit exceptions from totals.
Preserve exact workbook columns and report sections. The HTML templates must work
without network resources and support both restrained light and dark themes.

Domain files are authored. Files 06, 07, 08, and 11 are generated by the maintainer tools.
Change their source, regenerate, and run the checks; do not hand-edit generated content.
Release version and date come from `_maintainer/release.json`. Shared preflight lives
in `_maintainer/schema.py`; every emitted Office block must run independently outside
this repository. Finder metadata and measured budgets are generated and checked for
drift. Test package bytes against their source and preserve prior release evidence.
Build token usage is unknown unless backed by actual telemetry. Content token estimates
are a different measure and must be labeled with their calculation and exclusions.
Record build stages and verification outcomes honestly. Never invent duration or cost.
