The ten files may still be too large

Attachment count does not measure context capacity. Use the Example check, Analyze and Render stages defined in file 01. Preserve the complete case record between stages, including all rows, source locators, calculations, alternatives and unresolved checks.

File creation varies by session

No installation, terminal, connector or agent builder is required. Test the session's actual calculation and file capabilities. When a file cannot be created, the suite supplies structured text fallbacks. Code displayed in a chat is not evidence that an artifact was created.

The examples do not establish production performance

All worked cases are fictional. Reproducing them checks the stated exercise; it does not measure detection accuracy, regulatory compliance or live operating effectiveness. Consequential decisions remain with an authorized human.
